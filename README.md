# Product Pulse

Okay so we are building a web app where we are trying to do the work of product manager automatically.

So what our initial goal is to remove the manual work of the product manager by syncing github commits, PRs, Jira tickets,  google calender, meetings etc. you get the idea.

Now build a initial web app that solves exactly this problem and make the UI smooth and a bit different

This project was built with [Lovable](https://lovable.dev).
